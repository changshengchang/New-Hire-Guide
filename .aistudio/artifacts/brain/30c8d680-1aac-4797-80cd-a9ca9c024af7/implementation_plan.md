# 三義鄉公所新進人員指引系統 (Sanyi Township Office Onboarding Portal)

專為苗栗縣三義鄉公所人事室及新進同仁量身打造的現代化數位報到引導系統。整合新進公務人員到職流程、證件備妥清單、表單管理中心、行政大樓與附屬館舍環境圖文介紹、薪資開戶與國旅卡指南、MyData線上填表規範及內部共享磁碟【Z:\人事】引導。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 本系統兼顧新進人員友善指引與人事人員日常維護管理，規劃以下三大核心決策：

- **雙身分類別自動分流**：系統頂端提供「考試分發初任人員」與「他機關調任人員」一鍵切換，首頁與各模組自動過濾相應之證件需求（如初任之畢業證書/戶籍謄本 vs. 調任之前機關銜補單/離職證明書）及 MyData 應填表件。
- **人事管理員與新進人員雙視角**：
  - **新進同仁視角**：互動式報到檢查清單、清楚流程步驟、表單範本下載、環境空間瀏覽、導航指引與開戶須知。
  - **人事管理視角**：表單新增/上傳/更新中心（供新人下載）、各樓層環境介紹文字與實景相片上傳/更換管理。
- **在地與公部門規範落地化**：直接內建三義鄉農會開戶規定（雙證件、派令/報到單、起存1000元）、玉山銀行國民旅遊卡專區、公務人員個人資料服務網 (MyData) 法定具結規範、以及公所內部網路【Z:\人事】檔案夾位置說明與連線小撇步。

## 1. Overview & Core Concept

### What It Does
三義鄉公所新進人員指引系統是一套全功能報到引導與行政指引平台，讓初任或調任至三義鄉公所的同仁能在一站式介面中掌握：
1. **個人到職檢查清單**：按部就班完成報到手續、追蹤進度並可列印「報到進度確認表」。
2. **應繳證件與表單專區**：清楚區分初任與調任所需證件；提供人事室發布之空白報告表單下載與填寫範例。
3. **公所環境與課室導航**：完整收錄行政大樓 1F–6F（民政課、收發處、政風室、建設課、觀光產業暨農業課、鄉長室、秘書室、主計室、調解室、檔案室、會議室、財政暨行政課、人事室、公有零售市場、大型會議廳）及第二辦公大樓、圖書館、納骨堂、殯儀館等空間介紹，並支援照片即時更新上傳。
4. **金融與福利指引**：三義鄉農會開戶流程與應備文件，以及玉山銀行國旅卡特店與權益須知。
5. **MyData 線上具結申報專區**：四大必填法定表件（擬任人員具結書、初任服務誓言、兼職調查表、未在大陸設籍或領用證照具結書）操作與注意事項說明。
6. **公所公用資料庫位置**：清楚指示公所內網【Z:\人事】之掛載路徑與各類法規表件分類。

### Target Audience
- **新進同仁**（初任考試及格人員、各機關商調至三義鄉公所之公務人員、職代或約聘僱同仁）。
- **三義鄉公所人事室主管與承辦人員**（維持表單最新版、更新各辦公空間實景照片、解答常見問題）。

## 2. User Experience & Visual Design

### Visual Identity & Theme
- **設計風格**：莊重、親切且具客庄人文質感的公部門數位風格。融入苗栗三義特有的「木雕藝文」與「油桐綠意」色調，捨棄一般生硬的政府網站刻板印象與氾濫的 AI 紫藍漸層，呈現高質感、低視覺疲勞的人文辦公介面。
- **色彩系統 (60-30-10 比例)**：
  - **60% 畫布底色**：典雅暖米白／大地淡米底色 (`#F8F9FA` / `#FAF7F2`)，營造紙本閱讀般的安定感。
  - **30% 結構表面**：深墨藍灰 (`#1E293B`) 用於主要標題與字體，溫潤胡桃木色 (`#4A3B32`) 用於公所招牌與邊框分割。
  - **10% 重點色**：深邃客庄桐花墨綠 (`#1E4E3D`) 與典雅琥珀金 (`#B45309`) 作為按鈕、進行狀態與重要警示標記。
- **字體階層**：
  - 標題選用標準正體中文黑體搭配穩重西文 `Plus Jakarta Sans`，副標題與正文採用清晰易讀的 `Noto Sans TC`。
  - 序號、樓層（1F~6F）、金額（1,000元）、網路路徑（Z:\人事）等嚴格採用 `font-mono tabular-nums` 確保工整對齊。
- **排版紀律**：
  - 嚴格遵守 **Zero-Pill 規範**：元數據（如課室所屬樓層、更新日期、檔案大小）採用自然文字搭配 `·` 或 `/` 分隔符號，不用廉價藥丸膠囊包裹。
  - 一樓至六樓空間配置採用層級卡片與立體剖面概念展開，樓層資訊清晰一目了然。

### Key User Flows
1. **首頁進入與身分選取**：
   - 頂部顯示「三義鄉公所新進人員指引系統」，副區塊引導選擇「考試分發初任人員」或「調任人員」。
   - 首頁呈現動態報到流程看板（從報到第一天到第一個月重要待辦事項）。
2. **繳交證件與表單填寫模組**：
   - 依身分自動標示必備文件（如戶籍謄本、學歷證書、曾任機關年資證明或前機關銜補單）。
   - 人事表單下載區：人事人員可在此上傳各類 docx/pdf 檔案，新人點擊即可即時下載與預覽填寫注意事項。
3. **公所環境與樓層指引模組**：
   - 樓層選擇器（1F–6F、第二辦公大樓、圖書館、納骨堂、殯儀館）。
   - 點選樓層即可查看該樓層之課室清單、主要業務介紹、分機與實景照片。
   - 提供「上傳/更換相片」互動功能，人事同仁可隨時上傳最新公所實景照片。
4. **薪資開戶與國旅卡模組**：
   - 三義鄉農會開戶指引（三義鄉農會本會與辦事處地圖資訊、雙證件/派令或報到單要求、最低開戶金額 $1,000 元）。
   - 玉山銀行國民旅遊卡專區（申辦方式、檢核系統入口連結、刷卡補助原則）。
5. **MyData 線上具結與個人資料查驗**：
   - 四大法定表件操作指南，附上具結重點防呆提醒（如兼職情形規範、大陸地區設籍查核規定、初任誓言簽署）。
6. **公所共享資源【Z:\人事】**：
   - 圖文示範如何在公所內部電腦檔案總管連線至 `Z:\人事`。
   - 差勤管理系統、差旅費報支、文康活動與法令規範之內部路徑對照。

## 3. Key Product Decisions & Trade-Offs

- **決策一：前後台權限整合於流暢切換開關**
  - *選擇方式*：在右上角提供一鍵「切換視角」（「新進同仁視角」與「人事管理視角」），人事模式下解鎖表單上傳/刪除與樓層照片編輯功能。
  - *原因*：公所同仁在內部電腦使用時無需繁瑣的帳密忘記或重置問題，既能保證操作即時性，又清楚劃分兩種角色的使用情境。
- **決策二：本機儲存與狀態持久化 (LocalStorage & Data Export)**
  - *選擇方式*：新進同仁的檢核打勾進度、人事上傳的表單項目與樓層照片皆保存在瀏覽器本地存儲（IndexedDB / LocalStorage），支援一鍵重置與資料匯出。
  - *原因*：新進同仁免登入即可保留自己的報到清單進度，換日或重整頁面不遺失。
- **決策三：內建真實公所環境架構與標準公文/差勤範本**
  - *選擇方式*：預先載入完整的 1F~6F 課室資料（1F 民政課/收發、2F 政風/建設/觀光農業、3F 鄉長/秘書/主計、4F 調解/檔案/會議、5F 財行/人事/公有零售市場、6F 大禮堂）及各附屬機關預設景致。

- **狀態管理**：React 19 Hooks (`useState`, `useMemo`, `useEffect`) 統一管理新進同仁的檢查進度與人事維護清單。

## 5. Verification Plan

1. **身分過濾測試**：切換「初任」與「調任」，驗證繳交證件、MyData表件之篩選是否準確。
2. **表單上傳與下載測試**：人事管理模式下新增/刪除表單，確認新進人員模式下能正確下載。
3. **環境導覽與照片更新測試**：切換各樓層課室（1F~6F、第二辦公大樓、圖書館、納骨堂、殯儀館），測試照片上傳與及時反映。
4. **開戶與國旅卡驗證**：驗證農會開戶（雙證件、派令/報到單、起存1000元）及玉山銀行國旅卡資訊完整性。
5. **【Z:\人事】及 MyData 說明**：確認四大具結書檢核項目與 Z 槽路徑指引清晰。
6. **建置檢查**：執行 `compile_applet` 確認 TypeScript 與 Vite 建置無任何錯誤。
